# Flight Route Planner 
A Flight Route Planner project built using the Graph Data Structure in Python.  

This system represents airports as nodes and flight routes as edges to simulate real-world airline route planning and shortest path searching.




# Introduction
Air travel is one of the most complex transportation systems in the world, requiring efficient management of airports and flight routes.

This project applies the Graph Data Structure to model airline networks, where airports are represented as vertices and routes as weighted directed edges.  

Algorithms such as Dijkstra and BFS are used to find efficient flight paths between airports.

The project demonstrates how data structures can solve real-world problems in an organized and practical way.



# Problem Statement
Managing flight routes between multiple airports can become difficult when handling many connections at the same time.
Without an organized structure, route planning may become unclear, inefficient, and difficult to analyze.
This project uses Graph Data Structure concepts to organize airport connections and efficiently determine possible routes between airports.



# Project Objectives
- Understand the fundamentals of Graph Data Structure
- Apply graphs to model a real-world flight routing system
- Implement operations such as:
- Add Airport
- Add Route
- Search Airport 
- Find Shortest Path
- Demonstrate how data structures solve practical problems efficiently



# Limitations

- Uses a small dataset of airports and routes

- Focuses only on route planning

- Does not include:

- Ticket booking

- Live flight tracking

- Real airline databases

The Flight Route Planner demonstrates how Graph Data Structures can model real-world transportation systems efficiently.
